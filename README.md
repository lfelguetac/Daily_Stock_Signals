| **Pullback %** | Distancia del máx 20d | -5% a -15% = zona ideal |
| **RSI** | Momentum de corto plazo | 30-45 = sobrevendido (comprar) |
| **Trend** | Alineación SMA 20/50 | ↑↑ fuerte alcista, ↑ alcista, ↓ bajista |
