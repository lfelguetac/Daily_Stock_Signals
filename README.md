## 📖 Como Operar Estas Senales

### Reglas de Entrada
1. **Solo opera en la direccion del VWAP** — Precio sobre VWAP = solo LONGs. Precio bajo VWAP = solo SHORTs.
2. **Confirma con volumen** — Sin volumen > 1.5x, el movimiento puede ser falso.
3. **R:R minimo 1:2** — Si el target no da al menos 2x el riesgo, no entres.
4. **Maximo 2% de riesgo por trade** — Si tu cuenta es $10,000, arriesga maximo $200 por trade.

### Gestion de Posicion
- **Toma 50% en T1** — Asegura ganancias parciales cuando llegue al primer target.
- **Mueve stop a breakeven en T1** — Una vez que tomaste 50%, sube el stop al precio de entrada.
- **Deja correr el resto hacia T2/T3** — Con stop en breakeven, el resto es gratis.
- **Si el precio cruza VWAP en contra, SAL** — VWAP es la linea institucional. Si la cruza, la narrativa cambio.

### Cuando NO operar
- **Primeros 5 minutos** — Demasiado caotico. Espera a que se forme la primera vela de 15m.
- **12:00-1:00 PM ET** — Volumen bajo, movimientos falsos.
- **Sin volumen** — Si el vol ratio es < 1.0, no hay conviction institucional.
- **Contra la tendencia del SPY/QQQ** — Si el mercado general cae, no busques LONGs.

### Lectura de Indicadores
| Indicador | Que significa |
|-----------|--------------|
| **VWAP** | Precio promedio ponderado por volumen. Es el "precio justo" del dia. Las instituciones lo usan como referencia. |
| **EMA 9/20** | Medias moviles exponenciales. Cruce EMA9>EMA20 = momentum alcista. Cruce EMA9<EMA20 = bajista. |
| **RSI (15m)** | < 30 = sobrevendido (rebote probable). > 70 = sobrecomprado (correccion probable). |
| **ATR** | Average True Range. Mide la volatilidad. Se usa para calcular el stop loss (1.5x ATR). |
| **Vol Ratio** | Volumen del dia vs promedio. > 1.5x = hay dinero institucional entrando. |
| **Gap %** | Diferencia entre apertura y cierre anterior. > 3% = oportunidad de trade. |
